セロトニンやドーパミンが「出ている」とはどういう状態？主要ホルモン一覧つき

ひなたのひとこと 「ドーパミンが出てる」とか「セロトニンが足りない」とか、よく聞くけど正直どういう意味か分かってなかった。調べてみたら、体の中で起きていることが意外とシンプルだった。 セロトニンやドーパミンが「出ている」とはどういう意味？ 「ドーパミンが出ている」「セロトニンが不足している」という表現は、テレビやSNSでもよく見かけます。しかし、実際に体の中で何が起きているのかを説明できる人は少ないのではないでしょうか。 セロトニンやドーパミンは、脳の神経細胞どうしが情報をやり取りするときに使う神経伝達物質と呼ばれる物質です。神経細胞の先端から放出され、隣の神経細胞にある受け取り口（受容体）にくっつくことで、「やる気が出る」「気分が落ち着く」といった反応が引き起こされます。この放出される瞬間のことを指して、日常会話では「出ている」「分泌されている」と表現しているわけです。 なお、同じ物質でも脳の中で情報伝達に使われるときは「神経伝達物質」、血液に乗って全身の別の臓器に働きかけるときは「ホルモン」と呼ばれることがあります。セロトニンやドーパミンは主に神経伝達物質として扱われますが、この記事では分かりやすさを優先して、まとめて「脳内物質」として紹介していきます。 主要ホルモン14種のメリット・デメリット一覧 「幸せホルモン」と呼ばれるセロトニン・ドーパミン・オキシトシン・エンドルフィンに加え、血糖値や睡眠、食欲、体の成長に関わるホルモンまで、代表的な14種類を一覧にまとめました。整っているとどうなるか（メリット）と、乱れるとどうなるか（デメリット）をホルモンごとに見比べられるようにしています。 ホルモン名 分泌場所 メリット デメリット 整える習慣 セロトニン 脳（神経細胞） 気分が安定し穏やかになる 気分の落ち込み・不安・睡眠の質低下 日光を浴びる・リズム運動・バランスの良い食事 ドーパミン 脳（神経細胞） やる気・達成感が湧く 意欲低下／出しすぎは依存的行動につながる 小さな目標をこまめに達成する オキシトシン 脳下垂体 安心感・信頼関係が深まる 孤独感・人との関わりの希薄化 家族やペットとのスキンシップ・会話 エンドルフィン 脳下垂体など 高揚感が得られ痛みが和らぐ 得にくくなると高揚感・満足感が乏しくなる 運動・サウナ・適度な刺激 アドレナリン 副腎髄質 集中力・瞬発的な対応力が高まる 朝起きられない・無気力／過剰だと高血圧・不眠 十分な睡眠でストレスを溜めない コルチゾール 副腎皮質 血糖値調整・抗炎症作用で体を守る 慢性的に高いと心身への負担が増す ストレスをためすぎない・リラックス時間を作る メラトニン 脳の松果体 睡眠の質が上がり体内時計が整う 不眠・体内時計の乱れ 就寝前のスマホ利用を控える・朝に日光を浴びる 成長ホルモン 脳下垂体前葉 体の成長・回復・代謝を促進 疲労感・回復の遅れ 就寝後1〜3時間の質の良い睡眠・適度な運動 甲状腺ホルモン 甲状腺 全身のエネルギー代謝が活発になる だるさ・眠気・むくみ・体温低下・血糖値上昇 バランスの良い食事・規則正しい生活 インスリン 膵臓 血糖値を下げ安定させる 高血糖が続くと膵臓が疲弊し2型糖尿病リスク 規則正しい食事・運動不足解消・睡眠確保 レプチン 脂肪細胞 食欲を抑えエネルギー消費を促す 分泌低下で過食・肥満につながりやすい 十分な睡眠・規則正しい食事 グレリン 胃 空腹を知らせ適切な食欲を起こす 睡眠不足で過剰分泌し食べ過ぎにつながりやすい 十分な睡眠・就寝前の夜食を控える エストロゲン 卵巣など 女性らしい体づくり・骨の強さを保つ 加齢等で減少すると骨密度低下・体調の乱れ バランスの良い食事・適度な運動 オレキシン 視床下部 覚醒を保ち活動的になる 不足すると過眠・食欲の乱れ 規則正しい睡眠リズム 出典: 主なホルモンとその働き（東京女子医科大学）、ホルモンの働き（HELiCO） ...
